# 📊 Hiring Process Analytics Using Excel

## 📌 Project Overview

This project focuses on analyzing a company’s hiring process data using Excel to uncover meaningful insights related to recruitment, salaries, departments, and job positions. Acting as a Data Analyst at a multinational company like Google, the objective is to study hiring trends and workforce distribution to support better recruitment and organizational decisions.

The analysis includes data cleaning, handling missing values, outlier detection, salary analysis, and data visualization to better understand the company’s hiring patterns and employee structure.

---

# 🎯 Problem Statement

The hiring process plays a critical role in building a successful organization. Understanding patterns in recruitment data can help companies improve hiring strategies, optimize salary structures, and maintain workforce diversity.

This project aims to analyze hiring data to answer important business questions such as:

* What is the gender distribution of hires?
* What is the average salary offered by the company?
* How are salaries distributed across employees?
* Which departments have the highest workforce?
* How are employees distributed across different position tiers?

The insights generated from this analysis can help improve hiring efficiency and workforce planning.

---

# 🧹 Data Cleaning & Preparation

Before performing analysis, the dataset undergoes several preprocessing steps:

* Handling missing or null values
* Combining similar categories for easier analysis
* Detecting and managing outliers
* Standardizing data formats
* Cleaning inconsistent records

These steps ensure accurate and reliable analysis.

# 📊 Data Analytics Tasks

## A. Hiring Analysis

Analyzed the gender distribution of employees hired by the company.

### Objective:

Determine the number of male and female employees hired.

### Key Insight:

This analysis helps evaluate workplace diversity and gender representation within the organization.

---

## B. Salary Analysis

Calculated the average salary offered by the company using Excel functions.

### Objective:

Determine the overall average salary across employees.

### Key Insight:

Understanding average salary trends helps assess compensation standards and budgeting strategies.

---

## C. Salary Distribution Analysis

Created salary class intervals to study how salaries are distributed among employees.

### Objective:

Group salaries into ranges to identify common salary brackets.

### Key Insight:

This analysis helps identify salary concentration, pay gaps, and compensation trends across the workforce.

---

## D. Departmental Analysis

Visualized employee distribution across departments using charts and graphs.

### Objective:

Analyze the proportion of employees working in different departments.

### Key Insight:

Department-wise analysis helps understand workforce allocation and operational priorities.

---

## E. Position Tier Analysis

Analyzed the distribution of employees across different position tiers or levels.

### Objective:

Represent organizational hierarchy using visualizations.

### Key Insight:

This analysis helps identify workforce structure, management distribution, and career-level representation.
